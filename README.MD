# File Integrity Checker

A simple Python tool that calculates SHA256 hashes of files and later checks if any file has been modified or deleted.

This is a beginner-friendly cybersecurity project that demonstrates how systems can detect unauthorized changes to files.

## Features

- Create a baseline of file hashes (fingerprints)
- Verify files against the baseline
- Detect modified files
- Detect missing/deleted files

## Requirements

- Python 3
- No external libraries needed (uses only built-in modules)
